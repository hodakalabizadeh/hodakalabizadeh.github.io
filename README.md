# Academic website for GitHub Pages

1. Upload all files and the `projects` folder into the root of your `USERNAME.github.io` repository.
2. Upload your existing portrait as `headshot.jpeg` in the root, next to `index.html`.
3. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main / root.
4. Edit bracketed placeholders in `cv.html` and project pages.
5. Publications are maintained manually; the Google Scholar link is included but there is no automatic sync.
6. The CSS imports free Google Fonts; it falls back to Georgia and Arial when offline.
7. Change the year in the footer when needed.
